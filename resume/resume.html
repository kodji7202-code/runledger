Featured Project

RunLedger: receipts, cost and a real-time guard for AI coding agents2026 – present
Python 3.9+ · zero runtime dependencies · published on PyPI as runledger-ai · GitHub Action · Docker
  • Architected and shipped, through AI agents, ~17k lines of Python across CLI, parsers, risk engine and team server, backed by a 500+ test suite and CI on Linux, macOS and Windows.
  • Built agent adapters for Claude Code (stable), Codex CLI and Aider, plus an open native run format so any agent can emit receipts without a custom adapter.
  • Turned raw agent session logs into receipts (HTML/Markdown/JSON): files changed, every step in plain language, model, tokens and estimated cost per step, and a 0–100 risk score with explanations.
  • Implemented a real-time guard via Claude Code PreToolUse hooks: denies rm -rf, force pushes, curl | sh, DROP TABLE, hardcoded secrets; asks before sudo, .env reads or out-of-project writes; layered config where project policy can only tighten rules.
  • Built a team server: shared dashboard, role-based API keys with rotation, audit log, human-in-the-loop approvals routed to Slack/webhooks, team budgets with alerts, CSV/compliance exports, TLS and trusted-proxy support.
  • Shipped a CI gate (--fail-on threshold) and a GitHub Action posting a sticky receipt comment on every pull request.
  • Local-first and privacy-respecting: no telemetry; optional Claude-powered summaries only on explicit opt-in.
